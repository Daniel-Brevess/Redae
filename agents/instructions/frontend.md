# Instruções de frontend

- Preserve React + TypeScript + Vite + Tailwind CSS como base.
- Prefira componentes pequenos e sem abstrações genéricas antes de existir repetição real.
- Mantenha a interface responsiva, acessível e coerente com a identidade visual documentada.
- Não crie telas privadas, fluxos de autenticação ou integrações de API sem escopo explícito.
- Execute `npm run build` após alterações relevantes no frontend.
