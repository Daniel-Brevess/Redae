# Instruções de agentes

As instruções desta pasta são a referência de trabalho para agentes auxiliares e colaboradores. `instructions/general.md` é a base; os demais arquivos adicionam regras específicas por contexto.

As instruções são deliberadamente curtas, verificáveis e específicas ao repositório. Em caso de conflito, a solicitação atual e as regras do repositório têm prioridade.
