# Backend

Spring Boot mínimo para o Redaê. As dependências de persistência, segurança, JWT, validação, PostgreSQL e OpenAPI estão preparadas, mas nenhuma funcionalidade de negócio foi implementada.

O perfil padrão exclui a inicialização automática de banco para permitir que a aplicação suba sem credenciais. `application-example.yml` registra a configuração esperada para uma etapa futura de PostgreSQL.
