# Estrutura do repositório

`frontend/` contém a aplicação pública React. `frontend/private/` existe como espaço futuro para áreas autenticadas e permanece sem funcionalidades.

`backend/` contém um Spring Boot mínimo, sem controllers, services, repositories, entities, DTOs ou endpoints de negócio.

`agents/` mantém instruções operacionais por contexto. `docs/` mantém documentação curta e decisões. Workflows de CI ficam em `.github/workflows/`.
