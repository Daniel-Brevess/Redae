# ADR 0001 — Monólito modular no MVP

- **Status:** aceito
- **Data:** 2026-08-17

O projeto começará como um monólito modular em Spring Boot e não utilizará microservices no MVP. Uma eventual separação de serviços deverá ser justificada por uma necessidade real do sistema.

Nesta etapa não são criados módulos de domínio: a decisão registra somente a direção inicial e preserva a simplicidade da fundação.
