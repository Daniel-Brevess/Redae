# Visão do projeto

Redaê é uma plataforma de treinamento personalizado de redação para o ENEM. A primeira etapa entrega somente a fundação técnica e uma landing page pública.

## Stack

- Frontend: React, TypeScript, Vite e Tailwind CSS.
- Backend: Java 21, Spring Boot, Maven, Spring Web, JPA/Hibernate, Security, JWT, Bean Validation, PostgreSQL Driver e OpenAPI.
- Infraestrutura inicial: Vercel (frontend) e Render (backend).

Resend está reservado para confirmação de e-mail, recuperação de senha e comunicações da conta em uma etapa futura. Azure poderá ser explorado posteriormente para aprendizado e evolução da infraestrutura.
